A responsive, minimal, and high-performance Job Board platform named **Quantum**, engineered with **React + Vite + Tailwind CSS**. Built with a bespoke **Royal Blue** (`#1E3A8A`) and **Cream** (`#FAF7F0`) aesthetic, geometric **Hexagon** branding, smooth scrolling powered by **Lenis**, and full typographic identity utilizing Google’s **Outfit** typeface.

---

## ✦ Key Highlights & Architecture

### 1. Minimal Luxury Brand Identity
- **Hexagon Symbol**: Custom vector SVG hexagon badge featuring an inner geometric core and dynamic orbital pulse node.
- **Royal Blue & Cream Palette**: Deep royal blues (`#1E3A8A`, `#172554`), warm ivory creams (`#FAF7F0`, `#FDFCF8`), and subtle gold/amber accents.
- **Outfit Typeface**: Distinctive geometric styling rendered across all headings, metrics, badges, and components.
- **Lenis Smooth Scroll**: Buttery smooth inertial scrolling initialized smoothly for modern touch and mouse wheel ergonomics.

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/rohith10ty/quantum-job-board.git
cd quantum-job-board
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
